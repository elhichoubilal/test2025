قواعد Firestore
---------------
انسخ محتوى firestore.rules إلى: Firebase Console ← Firestore Database ← Rules ثم Publish.
بدون قاعدة rp_meta لا يُحفظ الأرشيف ولا الإعدادات المشتركة ولا الموظفون في السحابة.

إضافة قسم جديد (مثلاً الحاسبة)
------------------------------
1) أنشئ ملف js/mod-xxx.js فيه:
     App.register({ id:'xxx', icon:'🧮', title:['الحاسبة','Calculatrice'], order:40, render:function(el){ el.innerHTML='...'; } });
2) أضف في index.html قبل boot.js:
     <script src="js/mod-xxx.js"></script>
لا حاجة لتعديل أي ملف آخر. وللإضافة داخل بطاقة الزبون أو الجلسة من القسم الجديد:
     App.hook('contact.blocks', function(c){ return '<div>...</div>'; });
     App.hook('session.blocks', function(c){ ... });
     App.hook('msg.kinds', function(c){ return [{ id, label, text:function(){...} }]; });
     App.hook('dash.cards', function(){ return [{ ic, label, value, go }]; });
